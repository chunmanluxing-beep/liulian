第一步 · 令牌

怎样生成令牌(照着点三步,手机也能完成)
  1. 打开设置页。在手机或电脑浏览器登录 GitHub,访问 github.com/settings/personal-access-tokens/new
    (手动找的话:头像 → Settings → 最下面 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token)
  2. 只勾这一个仓库,只给读写内容。 名字随便填(例如 liulian-upload); 有效期 Expiration 选 1 year(一年); Repository access 选 Only select repositories → 选中 liulian-inbox; Permissions → Repository permissions → 找到 Contents,右边下拉选 Read and write。其余一律不用动。
  3. 生成并粘贴。拉到最底 → Generate token → 页面上会出现一串以 github_pat_ 开头的字符 → 点右边的复制图标 → 回到本页粘进下面的框 → 按「保存令牌」。
    这串字符只显示一次,离开页面就看不到了;丢了就照上面再生成一个,旧的可以删掉。

令牌只保存在这台手机/电脑的浏览器里(localStorage),不会发到别处, 本页也不含任何密钥。换设备要重新粘一次。
